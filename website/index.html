Install on
your iPhone

Build Scene Capture from source and sign it with your own Apple Account. You’ll need a Mac, Xcode, an iPhone 17 Pro and a USB data cable.

Download the source ZIP

The app checks both camera streams and depth rates before recording.

  1. Open the Xcode project

    Unzip the source download and open SceneCapture.xcodeproj. Launch Xcode once to finish its setup and install iOS platform support if prompted.

  2. Choose your signing team

    In Xcode → Settings → Accounts, add your Apple Account. Select the SceneCapture project, then the app target and Signing & Capabilities. Enable automatic signing and choose your team. A free account appears as Personal Team.

  3. Set a unique bundle ID

    Use an identifier of your own, such as com.yourname.iReal2Sim. Xcode will manage the development certificate and provisioning for that identity.

  4. Pair and unlock your phone

    Connect the iPhone and complete the trust prompts. Select the physical phone beside the SceneCapture scheme. If requested, enable Settings → Privacy & Security → Developer Mode, restart and confirm on the phone.

  5. Build and record a short test

    Choose Product → Run. In the app, tap Prepare cameras, grant camera access and check the Main, Ultra Wide and depth indicators. Keep the app in the foreground and start with about 15 seconds.

  6. Export the complete session

    Stop and wait for Complete. Copy the entire session folder to your Mac using the app, Files or Finder file sharing. Keep the folder intact for the pipeline.

Free Personal Team provisioning expires after seven days; rebuild in Xcode to renew it. See Apple’s account limits and Developer Mode guide.

Let your agent
run it

Open the unzipped source folder in Codex, Claude Code or another interactive coding agent. The repository’s AGENTS.md and local ireal2sim skill guide setup, credential checks, processing and resume.

Give the agent the prompt alongside. It can locate your recording, run the ready stages and open your scene dashboard.

Desktop dependencies

brew install uv ffmpeg cmake rtabmap
uv sync --frozen --python 3.12

Install Homebrew first if needed. Run these commands from the source folder, or ask your agent to set it up.

Captures are processed on your Mac. Optional vision review sends camera storyboards to OpenAI and uses your API account. Keys belong in local configuration, never in this webpage or the iPhone app.

Pipeline

Review uploads the Main and Ultra Wide storyboards to OpenAI and incurs API usage. The agent will ask you to configure an OpenAI key locally.

Prefer the dashboard?

Run ./start in the source folder. Open the local page, choose your exported session and click Build scene. You can add a vision-review key there when you opt in.

What runs today

The example scene shows the direction of the project. Here’s what to expect when processing a new recording.

Scan and source replay
Built in: capture validation, both-camera indexing, calibrated Main/LiDAR RGB-D, RTAB-Map poses, Open3D fusion, optional textures and paired camera replay.
Vision review
Optional OpenAI review proposes visible objects, surfaces and capture gaps. It produces an inventory to inspect against the original imagery.
Scene and interaction fitting
Full scene models and learned hand/object fitting require configured workers and their dependencies. The agent keeps stages that need setup available for a later resume.
The furnished demo
This demo includes authored structural and furniture refinements plus existing hand/bottle estimates. Hidden shape, dimensions, alignment and physical contact remain estimates.
Command-line plan and resume
uv run scene-capture workflow plan /path/to/session \
  --output workspaces/my-room --profile scan
uv run scene-capture workflow run workspaces/my-room
uv run scene-capture workflow status workspaces/my-room

Repeat workflow run to resume valid completed stages. Use --profile review when you want API review, or full for configured scene, hand and object workers.
